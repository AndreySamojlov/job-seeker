# Обновление стиля ссылок борды — 16.10.2026

## Изменение

По запросу пользователя ссылки в ячейках таблицы переведены на чёрный текст со сплошным коричневым подчёркиванием. Стиль ограничен ссылками таблицы Cockpit Engine; пунктирное подчёркивание `.tblissue`, используемое для информации при наведении, сохранено. Новая локальная версия Engine — `0.2.0a7`.

## Доставка

Пользователь явно разрешил отдельное обновление board на `127.0.0.1:8095` с кратким перезапуском. Образ собран офлайн от проверенного предыдущего образа `job-machine/board:ui-5ea29e3`, без подключения к БД и без секретов в build context. Live-контейнер заменён на `job-machine/board:linkstyle-a7-20261016-r1`; прежний контейнер сохранён остановленным под именем `job-machine-board-rollback-linkstyle-a6` для отката. Ограничения контейнера, mount и loopback публикация порта сохранены.

Полные очищенные идентификаторы, хеши артефактов и машинные проверки: [board-link-style-deploy.json](board-link-style-deploy.json). Источник локального пакета и его происхождение — [board-s1.json](../provenance/board-s1.json).

## Результат проверок

- `GET /healthz`, страница борды и CSS на `127.0.0.1:8095` ответили HTTP 200; CSS отдаётся с `Cache-Control: no-cache`.
- Ответ CSS содержит правило ссылок таблицы, чёрный цвет и сплошное подчёркивание; dotted-стиль `.tblissue` присутствует.
- После выкладки все восемь worker-контейнеров остались с исходными ID и image, работают; их health endpoints вернули HTTP 200.
- Новый board-контейнер работает и healthy. Контейнер предыдущего образа остановлен и сохранён как rollback.
- Запущенный в изолированном контейнере образ подтвердил Engine `0.2.0a7` и целевые CSS-правила. Использовался `docker build --network=none`.

Браузерный скриншот результата не снят: Computer Use остановил сессию, потому что не смог надёжно определить URL активного браузера. Проверка результата выполнена по фактическому HTTP-ответу сервера и содержимому опубликованного CSS. Тесты приложения не запускались; инструкции проекта запрещают тесты на действующей production БД, а для этой доставки выполнены изолированная проверка образа и read-only эксплуатационные проверки.
