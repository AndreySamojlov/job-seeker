# Vacancy fit S1

Локальный модуль оценивает уже назначенную пару по неизменяемому снимку фактов.
Постановка заданий принадлежит вызывающему коду (`store.create_job`); discovery,
triage и автоматический сбор данных сюда не входят. Завершённая оценка неизменяема.

Операции используют существующий `DATABASE_URL`; внешний ключ берётся только из
`TYPESAFE_API_KEY`. Не передавайте секреты аргументами командной строки.

```powershell
python -m job_machine.fit status
python -m job_machine.fit run-once
python -m job_machine.fit resume-blocked --candidate-id ID --vacancy-id UUID
```

`status` выводит только количества по статусам. `run-once` возвращает idle,
completed, retry_wait, blocked или lease_lost. Отсутствие ключа блокирует назначенное
задание без HTTP и без оценки. Диагностика CLI содержит только коды.

Worker фиксирует аренду отдельной транзакцией до HTTP и повторно читает время
после ответа. Store проверяет токен и срок аренды перед записью результата/ошибки.
Повтор использует сохранённый payload. Store назначает backoff от 30 до 3600 секунд,
учитывая больший допустимый Retry-After. После аварии между HTTP и commit возможен
повторный оплаченный запрос; завершённая оценка при этом не перезаписывается.

`resume-blocked` применяют после устранения причины блокировки: он разрешает
продолжение только blocked, сохраняя вход и число попыток. Несовместимая модель или
схема требуют пересмотра проекта, а не замены snapshot. Production-операции требуют
отдельного определённого задания; локальные DB-тесты запускают защищённым runner.

Синтетические ожидания качества находятся в `tests/fit/fixtures/quality.json`.
`python scripts/probe_vacancy_fit.py` не обращается к API. Только явный `--execute`
разрешает запросы с ключом из окружения; вывод содержит ID случая, оценку и
расхождение с диапазоном либо код ошибки. Диапазоны — исследовательские ориентиры,
не критерии приёмки качества модели; для переносимости диапазон оставлен открытым.
Неподтверждённое соответствие может получить 0, но Choice unknown не должен сам
подменять итог нулём. Fake transport проверяет контракт и lifecycle,
но не качество Jev. Реальный API и качество без такого запуска не проверены.
