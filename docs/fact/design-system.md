# Design System — FACT

Область: read-only dashboard из `dashboard/render.py` и `ops/dashboard.py`. Переиспользован server-side HTML; отдельной компонентной библиотеки/SPA нет.

Визуальный язык: system-ui/Segoe UI/Arial, тёмный фон #0f1115, светлый текст #e6e6e6, вторичный #8a909a, ссылки #6cb6ff. Карточки воронки используют flex-wrap, радиус8px, border #2a3038; таблицы занимают ширину страницы. Токены и точные размеры принадлежат CSS renderer, не дублируются как отдельная система.

Компоненты: карточки стадий, Other для дополнительных состояний, таблицы блокировок/готовых заявок/контейнеров, список попыток. Пустая очередь и отсутствие блокеров имеют текстовые состояния. Значения экранируются; ссылки разрешены только http/https. Кнопок submit/stop в панели нет.

Обновление — meta-refresh30 секунд. Исходный domain dashboard показывает время генерации UTC. Локальная ops OBS.S1 показывает время получения каждого блока и время событий отдельно в Europe/Moscow (+03:00), без зависимости от Windows tzdata. Stale/unavailable имеют явный текст role=status; детали очищенной ошибки раскрываются стандартным details/summary с клавиатуры. HTTP503 сохраняет общую страницу и доступные блоки. Кэш в ответе запрещён. Анимации отсутствуют; карточки переносятся, ops-таблицы имеют локальную горизонтальную прокрутку. Проверены synthetic viewport1280/390 и keyboard details, но полный аудит screen reader не проводился. Общий renderer не изменён. Пользовательские маршруты — [User Journeys](user-journeys.md).
