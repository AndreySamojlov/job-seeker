# Design System — FACT

Переиспользован существующий серверный HTML renderer `job_machine.dashboard.render`; SPA и новая визуальная система не создавались. Дополнены таблица runtime и результаты попыток. Значения сервисов HTML-экранируются; read-only интерфейс не содержит кнопок отправки или остановки. Unknown состояния не скрываются: исходный renderer показывает их в Other. Проектная панель доступна только на loopback.
