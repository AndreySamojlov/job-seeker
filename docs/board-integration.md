## Запуск и данные

Агент запустил борду на **http://127.0.0.1:18767/**. Это отдельный локальный процесс, использующий существующий PostgreSQL-туннель15433. Процесс не поднимает SSH, не перезапускает демон и не меняет его registry. `healthz` проверяет только HTTP-процесс. Успешный пустой отчёт имеет200/live; ошибка данных —503/unavailable с очищенным текстом; неверная выборка —422. Ответы данных имеют `Cache-Control: no-store`.

Воспроизводимая установка: `uv sync --frozen --all-groups --python 3.12`. Минимальный web-runtime: `uv sync --frozen --group board --python 3.12`. Команда процесса: `.venv\Scripts\python.exe -m uvicorn job_machine.board.app:create_app --factory --host 127.0.0.1 --port 18767 --no-access-log`; перед запуском агент проверяет занятость порта. Логи текущего процесса находятся в `.runtime/board-s1.stderr.log`; runtime metadata — `.runtime/board-processes.json`. Это локальный запуск без автозапуска ОС и без контейнерной поставки.

Пароль демона читается только в памяти из существующего разрешённого источника. Корневой `.env` не создаётся. Соединение фиксировано на loopback15433/job_machine и `default_transaction_read_only=on`; каждый отчёт использует repeatable-read/read-only с SQL timeout10 секунд. Будущая серверная поставка должна получить отдельную роль чтения; локальная credential-конфигурация не является серверной.

Начальный период — последние30 календарных дней в Europe/Moscow. Если за этот период данных нет, борда показывает пустую выборку. Два активных кандидата требуют явного выбора. Используются фактические текстовые `candidate_id`; ограничение UUID из переданного плана исправлено по схеме. Это локальная однопользовательская борда: выбор активного кандидата не является системой разграничения аккаунтов.

## Контракт

Оболочка, стили, фильтры, KPI, сцена1+3 и таблица полностью поставляются wheel через opt-in `register_board_routes`. Legacy routes, core DB и миграции движка не подключаются. Зафиксированные API — [board-v1](board-source/board-v1.md); происхождение wheel и документов — [manifest](../provenance/board-s1.json).

Версия0.2.0a2 восстанавливает native report-shell/page-shell/sheet/rail вместо альтернативной `.ce-board` вёрстки. Таблица использует общие hide/restore/resize/selection/copy/sort. Состояние колонок сохраняется при server refresh, ресурсы освобождаются на switch/destroy. При серверной пагинации native export явно выгружает текущую страницу; фильтры полной выборки находятся в rail. Результат source/package-проверки и ограничение визуальной приёмки — [исправление](../audit/board-native-ui.md).

Job Seeker поставляет GET `/api/board/greenhouse`, SQL и расчёты. Агрегаты относятся ко всей выборке; SQL-страница таблицы содержит до100 строк. Сортировка стабилизирована `vacancy_id`, неизвестные значения идут последними. Борд определяется только из допустимого сохранённого Greenhouse API URL; неподтверждённая идентичность не превращается в имя компании. Показатель бордов считает distinct token; неизвестные отдельно посчитаны.

Кандидатский LEFT JOIN не отбрасывает неоценённые вакансии. Фит0 сохраняется. Распределение и scatter различают версии рубрики; неопределённая версия подписана. Scatter исключает NULL fit с явным счётчиком. Среднее новых/день учитывает все календарные дни, включая нулевые, и не экстраполирует сегодня.

Историческая доступность не подтверждена надёжным whitelist происхождения статусов. Поэтому весь S1 возвращает `unknown`, дата проверки доступности отсутствует, KPI доступности и срока жизни — «Нет данных». `verified_at` не подменяет доказательство. В фильтре доступны «Все» и «Неизвестно»; они совпадают при текущем mapping. Никакой новой истории или проверок сайтов не создаётся.

## Проверки и ограничения

Команды baseline unit/smoke берутся из AGENTS.md; DB-suite запускается только через `scripts/check_schema.py` на проверенном recovery-кластере25439. Production используется только для отдельной read-only сверки `audit/verify_board_s1_live.py`, без фиктивных записей, browser/DB-suite или raw payloads.

Синтетический browser-стенд запущен на **http://127.0.0.1:18768/** через `tests.board.fixture_app:create_app`. Сценарий — `tests/board/browser-smoke.mjs`. Он проверяет1+3, страницы, смену кандидата, поздние ответы, пустоту,503, восстановление и modal. Его выполнение сейчас запрещено сохранённой настройкой Browser; исходный wheel также не имел завершённой browser acceptance. Наличие HTML/HTTP200 не считается визуальной проверкой.

Evidence, результат независимого review и незакрытые пункты — [audit S1](../audit/board-s1.md). Борда не заменяет Observer. На момент начала S1 Observer18766 не принимал соединения; S1 его не запускала и не останавливала. Workers остаются на прежних identities/images. Нет разрешения на миграции, реальные отклики или redeploy production.

Отложенные замечания review: сортировка борда идёт по token, хотя отображение также содержит label; максимальный ресурсный бюджет JSON/scatter не установлен. Реальная read-only выборка45 382 вакансий агрегируется с серверной страницей100, но браузерная производительность этого набора не проверена. Потребление ресурсов при произвольно большом периоде/числе оценок остаётся ограничением.
